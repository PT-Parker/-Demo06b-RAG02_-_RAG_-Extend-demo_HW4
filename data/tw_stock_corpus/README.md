# 台股知識庫 (Demo06b 延伸版)

此資料夾提供台灣股票市場的基礎知識，供 RAG 系統示範與教學使用。內容涵蓋：

- 市場與指數概況：集中市場 (TWSE)、上櫃 (TPEX)、櫃買指數、加權指數。
- 產業與公司示例：半導體、電子製造與幾家具代表性的上市公司簡介。
- 財報與名詞：常見財務指標、法遵與風險提醒。

範圍限制與警語：

- 僅為示範資料，非即時報價與非投資建議；資訊可能過時或簡化。
- 不包含任何內線或個別券商研究報告。
- 若需投資決策，請參考證交所/櫃買中心公開資訊觀測站或洽專業投資顧問。

使用建議：

- RAG 系統可直接讀取本目錄的 Markdown 檔，並以檔名作為引用來源。
- 可自行擴充更多公司或產業檔案，保持一檔一主題的粒度，利於向量檢索。
